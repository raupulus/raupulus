## 🧑‍💻 Acerca de mí

Soy un **desarrollador web full stack senior** con más de 15 años de experiencia, especializado en **backend PHP/Laravel**, **PostgreSQL** e **IA aplicada en producción** (RAG, agentes y automatización). Entusiasta y divulgador del **software libre** desde 2001, también administro sistemas **GNU/Linux** y desarrollo proyectos de **IoT y hardware libre** (sensores, estaciones meteorológicas y monitores de energía con ESP32 y Raspberry Pi conectados a mis propias APIs).

### 🎯 Especialidades
- **Backend & Arquitectura**: PHP, Laravel, Python, Node.js, APIs RESTful
- **Inteligencia Artificial**: Agentes IA, RAG, integración de LLMs en producción, automatización
- **Bases de datos**: PostgreSQL, MariaDB, MySQL, SQLite
- **Frontend Reactivo**: JavaScript, TypeScript, Vue.js (Vue 3), Nuxt.js, Angular, TailwindCSS
- **IoT & Hardware Libre**: ESP32, Raspberry Pi, Raspberry Pi Pico, Arduino, Sensores, LoRa / Meshtastic
- **Sistemas & DevOps**: GNU/Linux (Debian, Fedora, Gentoo), macOS, Docker, Bash scripting

## 📂 Proyectos Destacados

### 🔧 Herramientas de Desarrollo
- **[🚀 Debian Developer Conf](https://github.com/raupulus/debian-developer-conf)** - Script automatizado para configurar entornos de desarrollo en sistemas Linux y macOS
- **[⌨️ Python KeyCounter](https://github.com/raupulus/python-keycounter)** - Herramienta para contar pulsaciones de teclas en Linux/macOS con integración API y pantalla cliente por websockets para monitorización en tiempo real
- **[📱 Social Post Publisher](https://github.com/raupulus/python_social_post_publisher)** - Automatización para publicar contenido en múltiples redes sociales

### 🌐 Aplicaciones Web
- **[🏠 Mi Sitio Web Personal](https://github.com/raupulus/www.raupulus.dev)** - Portal personal para presentarme y mostrar mis proyectos e información
- **[🎮 JajaProject Discord Bot](https://github.com/raupulus/jajaproject_discord_bot)** - Bot de Discord con funcionalidades avanzadas para comunidades
- **[🌟 Jaja Web Platform](https://github.com/raupulus/www.jaja.raupulus.dev)** - Plataforma web para mostrar proyectos y contenido

### 🔬 Proyectos IoT
- **[🌦️ Raspberry Pi Pico Weather Station](https://github.com/raupulus/rpi-pico-gadget-weatherstation)** - Gadget con Raspberry Pi Pico para monitorizar el clima del entorno en tiempo real
- **[🌱 Smart Bonsai ESP32](https://gitlab.com/raupulus/esp32-smart-bonsai)** - Sistema automatizado para cuidado de bonsáis con ciclo de luz natural
- **[📊 API IoT Fryntiz](https://github.com/raupulus/api-fryntiz)** - API para IoT, recibiendo lotes de datos de estaciones meteorológicas, radares de vuelos, smart plants y más
- **[🌦️ ESP32 Bresser Weather Station](https://github.com/raupulus/esp32-weatherstation-bresser-read-868mhz-cc1101)** - Interceptor de datos de estación meteorológica Bresser usando ESP32 y módulo CC1101 para capturar comunicación 868MHz
- **[⚡ Raspberry Pi Pico Energy Monitor](https://github.com/raupulus/rpi-pico-energy-monitor)** - Monitor de energía con Raspberry Pi Pico para medir intensidad y tensión de dispositivos

### 🔋 Proyectos de Hardware
- **Sistema GPS vehicular** - Monitorización GPS con transmisión de datos vía módem
- **Controladores de carga solar** - Dos circuitos independientes para alimentar dispositivos IoT
- **Gestión de baterías recicladas** - Controladores para bloques de baterías de vapers y portátiles
